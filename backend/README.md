# Backend Documentation

This directory contains the backend services for the SmartSlides application. It provides an API for user authentication and handling AI requests to the Triton Inference Server.

## Project Structure

*   `main.py`: The entry point for the FastAPI application. It defines the API endpoints and logic for communicating with the Triton server.
*   `ai_model_client.py`: A standalone script for testing the connection to the Triton Inference Server and the model's inference capabilities.
*   `Dockerfile`: Configuration for building the backend Docker image.

## Setup and Installation

1.  **Prerequisites:**
    *   Python 3.8+
    *   pip

2.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
    *(Note: Ensure you have a `requirements.txt` file created based on the imports in `main.py`)*

3.  **Environment Variables:**
    Create a `.env` file in this directory with the following variables:
    ```
    TRITON_URL=localhost:8000
    APP_PORT=8001
    ```

## Running the Application

To start the FastAPI server:

```bash
python main.py
```

The server will start on `http://0.0.0.0:8001` (or the port specified in `.env`).

## API Endpoints

### Authentication
*   `POST /api/auth/login`: Authenticates a user and returns their role.

### AI Generation
*   `POST /api/ai/generate-slides`: Accepts a text prompt and returns a JSON structure for the presentation generated by the AI model.

### Health Check
*   `GET /health/`: Checks the status of the backend and the connection to the Triton server.

## Testing the AI Model

You can run the standalone client script to verify that the Triton server is reachable and the model is working correctly:

```bash
python ai_model_client.py
```
